# hyprland-dotfiles

Hyprland 0.56 (Lua-Config), Waybar im macOS-Stil, Rofi, Mako, Kitty. Theme: Catppuccin Mocha / Sakura.
Eingestellt fuer HHKB + EurKEY, drei Monitore (DP-1/2/3), niri-artige Keybinds.

Dateien liegen wie in `~/.config/`. Einspielen (sichert nichts, vorher Backup machen):

    cp -a .config/. ~/.config/

Keybind-Uebersicht im laufenden System: `Super+Shift+/`.
